D-19-1 is P1 rather than P2 because it is simultaneously (a) a CI-blocking regression on `main` and (b) a genuine WCAG accessible-name-uniqueness problem in a shipped, authenticated surface — not merely cosmetic. D-19-3 is P1: a full, multi-hour production worker outage is exactly the plan's P1 definition ("processing failure ... inaccessible primary workflow"), even though the code fix itself predates this register entry — the entry exists to close the documentation gap and record the incident where the plan requires it to live.
